# Credits

MedRay v2 is a new local-first implementation with its own modular architecture and original branding. The following projects informed its direction:

- [MedRay Workspace v1](https://github.com/Halo1211/medray-workspace) — archived predecessor and conceptual reference
- [MedRAX](https://github.com/bowang-lab/MedRAX) — inspiration for composable radiology tools
- [Odysseus](https://github.com/pewdiepie-archdaemon/odysseus) — project reference

Third-party packages remain subject to their respective licenses. See the dependency lockfiles for the exact resolved software used by this project.
