# MedRay v2

MedRay v2 is a local-first workspace for structured X-ray review, annotations, AI-assisted report drafting, model discovery, and research validation.

> **Important:** MedRay v2 is research, education, and prototyping software. It is not a medical device, PACS, RIS, diagnostic system, or emergency-triage tool. All output requires qualified human review.

## At a glance

```text
Import study -> route anatomy -> review systematically -> verify findings -> export a draft
```

Supported study groups include chest, MSK/trauma, abdomen/KUB, spine, skull/facial/sinus, and general/unknown X-ray profiles. The default Built-in Demo requires no model download and is intended to explore the workflow.
